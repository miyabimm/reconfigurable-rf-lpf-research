# RF-T008 v3 Phase 2 — EXP-062～064 コスト–IL観測パレートの横断更新

**状態：実験は実行・独立MNA・Git保管監査済み。ただしPRは3件ともdraft、`main`未統合。** 本ページは3つのPR上の監査済み数値を突き合わせた暫定閲覧用一覧であり、単一main SHAで統合済みの成果だとは主張しない。

## 研究対象

- 正本：RF-T008改訂v3。正式RF-F003は変更なし。
- 6設定、全28区間×1001点、固定外部S2P、50Ω源、60−j40Ω負荷。
- 必須H2/H3≥30dB、公称35dB目標、最悪IL≤0.30dB目標。
- 可変IC-C最大2枝。各枝のQ60固定IC-CはQ35可変Cと同じ両端へ並列に配置し、損失を別々に計算する。
- PCB-C：GND端Q60／0.02～1pF、Hot-Hot Q40／0.02～0.2pF、総数最大3。
- チップL Q25の相互結合 `|k|≤0.1`、L行列SPD、独立7×7（3L）または9×9（4L）結合L枝電流MNAと受動電力収支を確認。
- SLSQPは`slsqp-staged-v2`、粗240／精密120、停止理由に応じた1回だけの回復。

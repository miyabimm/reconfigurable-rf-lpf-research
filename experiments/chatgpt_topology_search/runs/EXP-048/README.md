## 検証深度・制約

- **実行済み：** 元RF-F003の6設定×28区間（各1001格子点、計28,028評価）、追加RF-T006の6設定×3,001点（3.000～6.000 GHz・1MHz刻み、計18,006評価）。全系の外部端子間`−10log10(Pload/Pavs)`を使用。入力側・出力側S2PはRF-F003で固定した元データとSHAを使用。外部寄生回路はLPF内部で50Ω終端しない。
- **別式独立検証PASS：** 明示的な9×9枝電流MNAで**114点**を解析（従来28区間の両端・中点84点＋3～6GHzの30点）。減衰量の数値差最大**4.48×10⁻¹³ dB**、電力収支残差最大**6.94×10⁻¹⁸ W**。114点のMNAと46,034点の縮約式を混同しない。
- **実行済みだが未収束／未証明：** 固定トポロジーのみの局所調整では可行候補が得られず、接続変更が重要だった。各局所反復の最終点は必ずしもベストではないため、途中の保存ベストを選抜した。**数学的最良・大域パレート・収束証明はない**。
- **未検証：** 連続周波数での極値保証、部品個別のQ(f)/SRF、EM・PCB/IC寄生、符号付き磁気結合の同時物理実現、公差・温度・歩留まり・実測。特に**21.29nH/24.38nHのLQP02HVを6GHzまで定数Q25とするモデルは実部品SRF上の懸念が大きい**。物理的な高周波20dB保証ではない。
- 元EXP-047は不変更。正式RF-F003と3可変C試験RF-T005の既存パレート実績へ混入させない。Phase 2継続、**Phase 3には移行しない**。

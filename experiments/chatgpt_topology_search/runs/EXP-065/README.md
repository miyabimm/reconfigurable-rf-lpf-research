# EXP-065: RF-T008 v3 Phase 2 / 4L2C 広域トポロジー探索

中央実験台帳 main に **EXP-065** 正式予約済み (2026-10-20T15:54:30Z)。
本タスクでいう 4L2C = 4×LQP02HV/Q25、2×GJM01/Q80 の固定チップC（chip-area 5⅓）。可変IC-Cは別分類で最大2枝、各枝はIC固定Q60+可変Q35で、全6設定共通固定C+各設定可変0..3pF。

## 探索範囲
8種類の固定コンデンサ接続（2 GJM + 2 PCB、PCBはGND Q60 0.02..1pF / hot-hot Q40 0.02..0.2pF）、4種類の複合DTC2枝接続、3種類の4-L枝電気接続を同時組合せ、計96回路を二つの異なる開始ベクトルから局所SLSQP (192 initial multistarts) で解く。

最新の基準: EXP-062実行済み・9x9 MNA PASS、面積5⅓ worst IL=0.8335054302993898 dB。実数ベクトルおよびトポロジーはこのEXP-065配下の `source_exp062_area5p333_best.json` に凍結して引用。もう一つの初期点はEXP-058面積5⅓に由来する。

拘束はRF-T008 rev3、外部入力・出力の固定Touchstone S2P、50Ω源/60−j40Ω負荷、6設定、28周波数区間×1001点、H2/H3必須各30dB、公称35dB、IL目標0.30dB。標準 `slsqp-staged-v2` 粗240/精密120、停止理由に応じて500/280または通常予算ウォーム再開。候補は全設定有限RF適合・両段階収束・独立9x9結合L MNA84点PASS後にのみ比較する。

96組合せは探索範囲を定める計算上の実験であり、制約内の全電気回路やグローバル最適性の証明ではない。SRF、Q(f)、EM、製造公差、連続周波数極値、実際の同時物理結合k、PCB/IC実面積、Phase3は未評価・未承認。実行済み / 未収束 / 実施前を峻別し、数値結果が得られるまでは改善と称さない。

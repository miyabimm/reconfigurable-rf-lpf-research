# EXP-063 — 3L・低コストRF-T008 v3 PCB-C配置探索

**現在の状態：数値実行前。** 新しい最良IL・パレート成果は未確認。

- main事前予約：EXP-063（2026-10-20T15:31:03Z）。研究Phase 2、Phase 3未承認。
- 目的：EXP-059で有効だった対GND PCB-C配置を3L/0GJM、3L/1GJM、3L/2GJMに移植して、各コストの最悪ILを改善する。
- L接続はEXP-058のT型3L、チップLQP02HV/Q25×3、物理列L0-Ls-L1、隣接|k|≤0.10。可変IC複合Cはshunt_output配置で2枝、各IC固定C/Q60および各設定Cvar/Q35を別々にstampする。
- 3Lで固定C位置の対照構成とGND付替え構成を各コスト4種、計12配置×2初期値＝24局所探索。
- RF-T008 v3は通常PCB-CのGND Q60、Hot-Hot Q40、IC固定C/Q60と可変C/Q35を遵守。外部固定S2P、全6設定、28区間×1001点、H2/H3必須30dB、公称35dB目標。
- SLSQPは新標準v2、粗240／精密120、termination-aware救済。
- 同じコストでも失敗・未収束を適合扱いせず、候補ごとに独立7×7 MNA84点と受動電力保存で確認。Q(f)・SRF・物理結合・公差・EM・実測は未実施。
